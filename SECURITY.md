# Security policy

## Supported versions

This project has no release yet. Fixes go to the `main` branch only.

## Report a vulnerability

Do not report a vulnerability in a public issue, a pull request, or a discussion.

Report it privately on GitHub instead.
Open [a new security advisory](https://github.com/exoego/keycloak-fuhito/security/advisories/new) from the Security tab of this repository.

Please include these.

- The commit or version that you used, and the version of Keycloak.
- What an attacker can do, and what they need first, such as a role or a token.
- The steps to reproduce it.

The report stays private until a fix is out.

## Vulnerabilities of Keycloak

A vulnerability of Keycloak itself, not of this extension, goes to the Keycloak project.
See its [security policy](https://github.com/keycloak/keycloak/security/policy).
